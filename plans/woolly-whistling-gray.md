# 出差费用报销填写计划

## Context
帮蔡劢报销出差费用。出差事由：2026远东论坛，部门：自动化部，项目号：104，出差人数5人（蔡劢、陈建华、付汝龙、张慧仪、孙伟成）。需要根据发票和模板填写报销单和差旅审批表。

## 步骤概览

### 步骤1：提取发票数据
使用 Python (pdfplumber/pymupdf) 从13张PDF发票中提取：类型、金额、日期、乘车人等关键信息。
- 如果PDF是扫描件（无文本层），则尝试使用OCR（pytesseract）或手动从发票分析中提取。

### 步骤2：创建发票明细.xlsx
按照 skill 要求的格式，将13张发票整理成明细表：
- 列：序号、名称、金额、发生日期、备注
- 类型排序：长途交通费 → 市内交通费 → 住宿费，同类型按日期排序
- 表末按类型小计，汇总总额（用Excel公式）

### 步骤3：填写差旅审批表（附表一）
- 拷贝模板为"差旅费报销审批表-草稿.xlsx"
- 填写第二页"附表一 差旅费审批表"第3~36行
- 处理超标项目（飞机票、市内交通单程>100元、住宿>300元/晚）
- 长途交通费按航班/车次合并，市内交通费逐日统计

### 步骤4：填写出差费用报销单
- 填写第一页"出差费用报销单"第4~15行
- B5填写"蔡劢等5人"
- 第10行不填，附单据张数用中文大写
- 出差补贴按每人每天100元

### 步骤5：核对
核对三个表格数据一致性。

## 关键文件
- 模板：`.claude/reimbursement_v1.1/出差费用报销单（创新中心版本）.xlsx`
- 例子：`.claude/reimbursement_v1.1/出差费用报销单（创新中心版本）-例子.xlsx`
- 发票目录：`.claude/reimbursement_v1.1/发票/`（13张PDF）
- 输出：发票明细.xlsx、差旅费报销审批表-草稿.xlsx

## 当前阻塞
PDF发票为图片扫描件，需要先用Python尝试提取文字。若pdfplumber/pymupdf无法提取，需要用户手动提供发票信息或安装OCR。
